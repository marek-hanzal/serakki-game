# Serakki

> Merge, craft, build and discover unexpected combinations. Download free Serakki Mini for Windows, macOS and Linux. The full game is in development.

Canonical page: https://serakki.dev/

This is the factual text reference for the illustrated homepage.

## Play and experiment

Merge. Craft. Build. Discover.

Serakki is an offline, data-driven economy game for desktop. Combine items on a Board, discover recipes and run production. The website includes interactive Board, production and Editor previews; these require JavaScript. The native desktop game is a separate application.

## Serakki Mini

Serakki Mini is free to download for Windows, Mac and Linux. It plays offline and does not include the Editor.

Mini is a complete, compact offline merge and crafting game with its own content and community worlds. Serakki goes bigger, with the original Serakki world and the Editor.

## The full Serakki game

Mini is a complete, compact adventure. Serakki takes you further.

- The Serakki experience: A rich world of combinations, small dungeons and puzzles hiding rare materials.
- Free seasonal content & paid DLC: More worlds and content are planned beyond the base game.
- The World Editor, included: Create worlds others can play, with your own rules, creatures and recipes.

The full game is in development.

## Create and share worlds

Creatures, recipes, art and music. Give them your rules.

The Board plays alongside your edits. Change a rule. Try again.

Share your worlds with other players. Mini-compatible worlds run in Serakki Mini; other worlds require the full Serakki game.

## Agents and MCP

Optional MCP tools for the desktop Editor.

Give it an idea. Your agent can generate and import artwork, then build items, recipes and whole Boards with MCP.

Your agent moves items and runs production. Work together, or let it play on its own.

It sees real artwork and Board screenshots, checks the outcome and adjusts the rules.

Agent tools are an optional authoring feature. Artwork generation uses the connected agent's image tools; the Editor's MCP can import artwork, return actual artwork previews and capture Board screenshots.

MCP connections belong to the desktop Editor. The website's Editor preview uses a temporary in-memory project; it does not provide native project import, Build, filesystem access or an MCP server. The website's Boards are independent sessions; items cannot be transferred between them.
